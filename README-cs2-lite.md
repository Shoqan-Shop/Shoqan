# CS2 LITE — лёгкая копия Counter-Strike 2

Браузерный шутер в духе CS2 в **одном HTML-файле** (`cs2-lite.html`), без движков,
библиотек и внешних ассетов. Просто открой файл в браузере и играй.

## Как запустить

Двойной клик по `cs2-lite.html` — или, если хочется отдать по сети:

```bash
npx http-server . -p 8080   # затем http://localhost:8080/cs2-lite.html
```

## Управление

| Клавиши | Действие |
|---|---|
| `W A S D` | движение |
| мышь | обзор (клик по экрану — захват курсора) |
| ЛКМ | огонь |
| ПКМ | прицел AWP |
| `R` | перезарядка |
| `1` `2` `3` | основное / пистолет / нож |
| `Q` | быстрая смена оружия |
| `G` | бросить гранату |
| `B` | магазин (первые 20 секунд раунда) |
| `Shift` | тихий шаг |
| `Esc` | пауза |

## Что внутри

* **Рейкастинг-движок** (DDA по сетке 32×32) с текстурированными стенами, полом
  и наклоном взгляда; спрайты врагов рисуются билбордами с честным z-буфером.
* **Процедурные текстуры и спрайты** — песчаник, бетон, ящики, металл, бойцы CT/T,
  трупы, граната, взрыв. Ни одного внешнего файла; затемнение по дистанции
  считается заранее в 32 уровня яркости.
* **Боты**: поиск пути в ширину по сетке, линия видимости, время реакции, стрейф
  на ближней дистанции, реакция на звук выстрелов, разброс и падение урона
  с расстоянием. Три уровня сложности, состав оружия растёт по ходу матча.
* **Стрельба как в CS**: отдача уводит прицел вверх и восстанавливается, разброс
  растёт в движении, хедшоты, броня и шлем, урон по зонам.
* **Экономика и раунды**: покупка оружия, кевлара и гранат, награда за убийство,
  бонус за победу и серию поражений, потеря основного оружия при смерти,
  матч до 10 побед.
* **HUD**: HP, броня, патроны, деньги, таймер, счёт, лента убийств, миникарта
  с радарными контактами, маркеры попаданий.
* **Звук** — синтезируется на лету через WebAudio (выстрелы, попадания, взрывы,
  перезарядка, шаги).
