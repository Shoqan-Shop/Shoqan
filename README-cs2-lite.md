# CS2 LITE — лёгкая копия Counter-Strike 2

Браузерный шутер в духе CS2 в **одном HTML-файле** (`cs2-lite.html`), без движков,
библиотек и внешних ассетов. Просто открой файл в браузере и играй.

## Как запустить

Двойной клик по `cs2-lite.html` — или, если хочется отдать по сети:

```bash
npx http-server . -p 8080   # затем http://localhost:8080/cs2-lite.html
```

## Матч

Шесть раундов **3 на 3**: ты и двое напарников против трёх противников.

* **Раунды 1–3 — ты террорист.** C4 у тебя: дойди до точки **A** или **B**,
  встань и удерживай `E`. Заложил — держите точку до взрыва.
  Погибнешь с бомбой — она упадёт на пол, и её подберёт напарник.
* **Раунды 4–6 — стороны меняются**, ты играешь за контр-террориста:
  не дай заложить C4, а заложенную сними тем же `E`. Экономика при смене
  сторон обнуляется.
* **Смерть — не конец раунда**: камера переходит к живому напарнику,
  и бой продолжается без тебя. Раунд проигран, только когда полегла вся команда.
* Время вышло, а бомбу не заложили — раунд за контр-террористов, как в CS.

## Управление

| Клавиши | Действие |
|---|---|
| `W A S D` | движение |
| мышь | обзор (клик по экрану — захват курсора) |
| ЛКМ | огонь |
| ПКМ | прицел AWP |
| `R` | перезарядка |
| `1` `2` `3` | основное / пистолет / нож |
| `Q` | быстрая смена оружия |
| `G` | бросить гранату |
| `E` | заложить или снять C4 (удерживать) |
| `B` | магазин (первые 20 секунд раунда) |
| `Shift` | тихий шаг |
| `Ctrl` / `C` | присесть — точнее стрельба, ниже силуэт |
| `Esc` | пауза |

## Что внутри

* **Рейкастинг-движок** (DDA по сетке 24×24) с текстурированными стенами, полом
  и потолком, наклоном взгляда и реальной высотой глаз; спрайты бойцов рисуются
  билбордами с честным z-буфером.
* **Бойцы рисуются процедурно** — три ракурса (спереди, сзади, в профиль) и две
  фазы шага на команду. Ракурс выбирается по тому, куда боец повёрнут относительно
  камеры, есть контур силуэта и контактная тень под ногами. Пропорции человеческие:
  рост около 1,75 м при глазах игрока на 1,6 м.
* **Процедурные текстуры** — песчаник, бетон, ящики, металл, пол, потолок с балками.
  Ни одного внешнего файла; затемнение по дистанции считается заранее в 32 уровня.
* **ИИ обеих команд**: поиск пути в ширину, линия видимости, выбор ближайшей видимой
  цели из чужой команды, время реакции, стрейф на ближней дистанции, реакция на звук
  выстрелов. Боты воюют между собой, террористы носят и закладывают C4,
  контр-террористы бегут её снимать (но не станут, если рядом живой враг).
* **Стрельба как в CS**: у автоматов отдача идёт по узнаваемому рисунку —
  сначала строго вверх, затем уводит влево и мотает вправо-влево, так что спрей
  можно выучить и компенсировать мышью. Разброс растёт в движении и падает
  в приседе, есть хедшоты, броня и шлем, падение урона по дистанции.
* **Обратная связь боя**: искры от пуль в стенах, брызги крови, вылетающие гильзы,
  маркер попадания, дуга с той стороны, откуда прилетело, тряска камеры.
* **Экономика**: покупка оружия, кевлара и гранат, награда за убийство,
  бонус за победу и за серию поражений, потеря основного оружия при смерти.
* **HUD**: HP, броня, патроны, деньги, таймер раунда и C4, счёт матча, состав
  своей команды с полосками здоровья, лента убийств, миникарта с точками A/B,
  напарниками, радарными контактами и заложенной бомбой.
* **Звук** — синтезируется на лету через WebAudio (выстрелы, попадания, взрывы,
  писк C4, перезарядка, шаги).

## Сложность

Это не один множитель, а целый профиль поведения противников:

| | Лёгкая | Средняя | Сложная |
|---|---|---|---|
| HP врага / броня | 65 / нет | 100 / с 3-го раунда | 100 / всегда |
| оружие врагов | пистолеты, MP5 | всё, вплоть до AWP | всё, раньше |
| реакция | 0,85–1,5 с | 0,22–0,5 с | 0,13–0,3 с |
| меткость | 20 %, падает с 14 клеток | 62 %, с 30 клеток | 85 %, с 40 клеток |
| урон / хедшоты | 55 % / почти никогда | 100 % / 12 % | 115 % / 20 % |
| скорость, обзор | 0,65×, 12 клеток | 1×, 24 клетки | 1,15×, 26 клеток |
| меткость напарников | 32 % | 45 % | 55 % |
| C4: взрыв / закладка / снятие | 55 / 4,5 / 4 с | 40 / 3,2 / 5 с | 35 / 3,2 / 6 с |
| деньги на старте | $2000 | $800 | $800 |

Проверено симуляцией: без участия игрока напарники вытягивают раунд на лёгкой
сложности примерно в 4 случаях из 5, а на средней и сложной — ни разу.
По умолчанию выбрана лёгкая.

## Настройки

Чувствительность мыши, инверсия вертикали, сложность и качество графики
сохраняются в `localStorage` и подтягиваются при следующем запуске.

## Производительность

Рендер занимает ~1,5–2,2 мс на кадр (проверено в Chromium на трёх уровнях
качества: 400×225, 520×292, 680×382 с масштабированием на весь экран).
